# StudyFlow Priority — AI 시험 대비 공부 우선순위 분석기

기존 자동 일정 관리 StudyFlow와는 다른 프로젝트입니다. 사용자가 과목/시험일/준비도/남은 공부량/중요도를 입력하면 자체 알고리즘으로 우선순위를 계산하고, 선택적으로 Gemini API가 학습 전략을 분석합니다.

## 실행

```bash
npm install
npm run dev
```

로컬 개발에서는 Vercel API가 자동 실행되지 않습니다. 실제 Gemini 호출 테스트는 Vercel 배포 환경에서 진행하세요.

## Vercel 배포

1. ZIP 압축을 풀고 **안쪽 파일과 폴더**를 GitHub 저장소 최상위에 업로드합니다. `package.json`이 최상위에 있어야 합니다.
2. Vercel에서 해당 GitHub 저장소를 Import합니다. Framework Preset: Vite, Build Command: `npm run build`, Output Directory: `dist`.
3. Vercel → Project → Settings → Environment Variables에서 `GEMINI_API_KEY`를 등록하고 다시 배포합니다.
4. 배포 주소를 학교 컴퓨터에서 열어 과목 추가, 분석, 시뮬레이션, Gemini 분석을 테스트합니다.

**주의:** API 키를 GitHub, React 소스코드, PPT에 입력하거나 공유하지 마세요. 공개 서비스의 AI API는 악용·사용량 초과 가능성이 있으므로 Vercel/Google AI Studio에서 사용량을 모니터링하세요. 이 버전은 로그인/공유 DB 없이 브라우저 localStorage로 각 사용자의 데이터를 분리합니다. 다른 브라우저나 기기로 옮기면 데이터가 동기화되지 않습니다.

## 핵심 알고리즘

`우선순위 = 0.32×긴급성 + 0.28×준비 부족도 + 0.23×남은 공부량 지표 + 0.17×중요도 지표`

- 긴급성: `100/(1+남은 일수/4)`
- 준비 부족도: `100-준비도(%)`
- 공부량 지표: `100×(1-exp(-남은 시간/12))`
- 중요도 지표: `중요도(1~5)×20`

모든 지표는 0~100 범위이며, 가중치는 발표용으로 설계한 **휴리스틱**으로 실제 성적 예측이나 통계적으로 검증된 모델이 아닙니다. 7일 시간 배분은 15분 단위의 참고용 그리디 알고리즘입니다.

## 발표 시연

1. 초기 빈 화면에서 '과목 추가'로 직접 입력하는 모습을 보여줍니다.
2. '예시 데이터'를 눌러 4과목의 우선순위와 계산 근거를 확인합니다.
3. '상황별 우선순위 실험'에서 시험 날짜를 앞당기고 전후 순위를 비교합니다.
4. 'Gemini AI 학습 분석'에서 실제 API 분석을 요청합니다.
5. AI 호출이 실패해도 우선순위 계산과 시뮬레이션은 작동합니다.
